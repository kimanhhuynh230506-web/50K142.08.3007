# YÊU CẦU PHI CHỨC NĂNG (NON-FUNCTIONAL REQUIREMENTS)

## Yêu cầu về khả năng sử dụng (Usability requirements)

|  |  |
|----|----|
| **ID** | **Non-functional requirements** |
| NFR-01 | Hệ thống chạy trên nền tảng web, khách hàng truy cập bằng trình duyệt qua mã QR và không cần cài đặt ứng dụng. |
| NFR-02 | Giao diện tối ưu để sử dụng thuận tiện trên điện thoại, cả khi khách đặt món lẫn khi chủ quán xem đơn và theo dõi thanh toán. |
| NFR-03 | Giao diện dùng màu đỏ làm màu chủ đạo, có thể kết hợp thêm màu xanh lá. |
| NFR-04 | Sơ đồ bàn hiển thị mỗi trạng thái một màu: xanh biển và vàng, để chủ quán dễ phân biệt bàn trống và bàn đang phục vụ. |
| NFR-05 | Hiển thị hình ảnh minh họa cho từng món để khách dễ nhận biết và chọn món; món không có hình thì dùng hình mặc định. |
| NFR-06 | Giao diện dễ dùng cho người không rành máy móc, cỡ chữ vừa phải, dễ đọc. |

*Bảng 30. Yêu cầu về khả năng sử dụng (Usability requirements)*
